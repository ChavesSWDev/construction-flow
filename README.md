## About

A corporate website template for construction and engineering companies, built to present services, completed projects and credentials in a way that builds trust and turns visitors into qualified leads.

> This is a showcase repository for a client project. The source code is private.

## Highlights

- 🏗️ **Service and project showcase** — sections for services, portfolio of completed works and company credentials.
- 🤝 **Credibility first** — layout and copy structure focused on trust for high-value B2B and residential clients.
- 📱 **Fully responsive** — works across desktop, tablet and mobile.
- 📈 **Lead conversion** — clear quote requests and contact paths throughout the page.

## Tech stack

`React` · `Vite` · `JavaScript` · `Responsive design` · `Vercel`
