## About

A corporate website template for construction and engineering companies, built to present services, completed projects and credentials in a way that builds trust and turns visitors into qualified leads.

> This is a showcase repository for a client project. The source code is private.

## Highlights

- 🏗️ **8 sections** — home, about, team, services, projects, blog, FAQ and contact.
- 🖼️ **Project showcase sliders** — Keen Slider galleries with Framer Motion animations.
- 🧱 **Modular component architecture** — built for long-term maintainability.
- 📈 **Lead conversion** — clear consultation requests and contact paths throughout the site.

## Tech stack

`React` · `Vite` · `Tailwind CSS` · `Framer Motion` · `Keen Slider` · `React Router` · `Vercel`
